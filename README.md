## 🚀 Getting Started

### Prerequisites
- Node.js >= 20
- pnpm >= 9

### Installation & Local Run

```bash
# Clone the repository
git clone https://github.com/dilliprasadm/mahashivaya_hotel.git
cd mahashivaya_hotel

# Install dependencies
pnpm install

# Start local development server
pnpm dev

# Build for production
pnpm build

# Start production server
pnpm start
```
